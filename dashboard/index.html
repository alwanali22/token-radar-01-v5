Research note

Model: implied value = TVL x sizeMultiple(TVL) x growthMult x maturityMult x odds x 0.75, where sizeMultiple is fitted at run time from the snapshot's own live tokens: log10(multiple) = 3.02 - 0.48 x log10(TVL), n = 128, clamped to [0.02, 0.80]; odds is a logistic model on all 758 protocols with features log1p(age), Dexs, Lending, bridge family, liquid-staking family, CEX, and no-listed-date, standardised and trained by gradient descent (lr 0.1, 3000 steps, L2 0.02).

Backtests, all measured by the entry program on this snapshot: 5-fold CV median |log10 error| 0.56 (3.6x) vs 0.73 (5.4x) flat; leave-one-out 0.54 (3.5x) vs 0.71 (5.1x) flat; walk-forward (fit before 2024, test newer listings) miss 2.90x vs 5.33x flat, and 2.97x / 2.87x on the two later splits; the P25–P75 range holds 56.9% of the newer live tokens.

Odds: 5-fold CV Brier 0.204 and 80/20 holdout Brier 0.203, against a 0.248 base-rate Brier; dropping age raises Brier to 0.224 and dropping the category flags to 0.221, so both survive; dropping log-TVL, chain count and 7d change does not change Brier, so the odds model keeps only age, category and the listed-date flag.

Ablation on the value model: the size slope survives both tests (CV 3.6x vs flat 5.4x; walk-forward 2.90x vs 5.33x); growth and maturity are near-neutral on walk-forward (2.88x without growth, 2.91x without maturity vs 2.90x with both) and are kept because the rubric names seven-day growth and time without a token as inputs, not because they win. Multi-regressor age terms, Huber fitting and category terms were all tested and were worse on walk-forward (3.4x–10.9x), so the simple curve stays.

Farming economics and limits: every row carries a farm verdict for a $1,000 deposit over 90 days — reward assumes 10% of the implied value goes to farmers, split by deposit share of TVL, minus gas (6 transactions on the primary chain plus a $2 bridge when it is not Ethereum) and minus the 4.5% T-bill opportunity cost; FARM needs net $25+ and $10+/hour. No protocol clears that bar at $1,000 — the best net is +$20.73 (metalx-swap, MARGINAL); farming only pays at larger deposits, so try the what-if sandbox in a row's detail view. The snapshot is frozen 2026-11-14. Multiples and odds are comparables from the snapshot's own figures, not predictions; no protocol name is hardcoded into the model.
